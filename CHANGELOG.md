# Changelog

## 0.3.0

- Add verified one-root and multi-root project scopes without merging distinct sessions that share a directory, title, or family.
- Add paginated session reading, visible-history search, restart handling, and explicit coverage metadata.
- Add Windows setup and restart helpers, privacy and security documentation, and reconstruction prompts.
- Apply the same recursive privacy exclusions to native and local-recovery payloads, including nested reasoning, private roles, binary data, collaboration status, and patch data behind the separate diff opt-in.
- Restrict local JSONL recovery to recognized transport and size failures; permission, policy, coded, and unclassified App Server errors fail closed.
- Apply the same private-phase and inline-data filtering to advanced native and compatibility search results.
- Keep all eleven MCP tools read-only and use state-database-only discovery.
- Pin the official MCP Python SDK to version 2.2.0.
